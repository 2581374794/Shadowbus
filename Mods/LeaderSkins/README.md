# LeaderSkins —— 官方素材补图

有些主战者的 UI 素材**官方客户端压根没发**（不是加载失败、也不是编号不同）。插件
（`LeaderSkinAssetFallback`）在本地找不到某个素材包时，会先看这个目录里有没有对应的 PNG：
有就直接用它；没有才退回到"同一角色的其它皮肤 / 同一皮肤的另一类素材（按官方尺寸裁切）"。

## 目录结构

按**皮肤号**建子文件夹，一个皮肤一个文件夹：

```
Mods/LeaderSkins/
  4102/                         <- 皮肤号（韦斯）
    btn_deck_4102.png
    class_4102_base_win.png
    class_4102_base_lose.png
```

文件名 = **官方素材名**（不含扩展名）+ `.png`。插件两种放法都认：先找 `<皮肤号>/<素材名>.png`，
找不到再看 `LeaderSkins/<素材名>.png`（兼容直接平铺的旧放法）。

## ⚠️ 放图之前先确认"构图"跟国际服一致

不同客户端/不同版本的同名素材，**画布尺寸可能一样但人物构图不一样**（国服手机版的素材
常把人画得更满）。构图对不上时不要放进来——插件拿同一皮肤的官方立绘按官方尺寸裁切，
反而更接近正常皮肤。

踩过的坑（4102 实测）：

| 素材 | 国际服正常皮肤 | 国服 4102 | 结论 |
| --- | --- | --- | --- |
| `btn_deck_*`（卡组立绘） | 宽条、左半边人物+背景 | 同一构图 | ✅ 可用国服的 |
| `class_*_base_win/_lose`（胜利/失败立绘） | 全身 | 全身、比例一致 | ✅ 可用国服的 |
| `class_*_profile`（资料图） | **全身**立绘 | **半身**，人物大一圈 | ❌ 不用，交给插件用官方立绘 |
| `class_skin_*`（皮肤缩略图） | 胸像 | 更紧的胸像 | ❌ 同上 |
| `class_select_thumbnail_*`（选择按钮图） | 头肩/脸，留有边距 | 整张脸铺满、头顶被切 | ❌ 同上 |

所以 4102 只放了前两类；缩略图/按钮图/资料图由插件拿国际服自带的
`ui_class_4102_base`（官方立绘）按官方尺寸（512×512 / 256×256）裁成半身像使用。

## 各文件名的用途与官方尺寸

| 文件名 | 用在界面上的位置 | 官方尺寸 |
| --- | --- | --- |
| `class_skin_<皮肤号>.png` | 皮肤缩略图 | 512×512 |
| `class_select_thumbnail_<皮肤号>.png` | 主战者选择按钮图 | 256×256 |
| `btn_deck_<皮肤号>.png` | 卡组列表上的主战者立绘 | 1024×256 |
| `class_<皮肤号>_base.png` | 战斗全身立绘 | 2048×2048 |
| `class_<皮肤号>_base_win.png` / `_base_lose.png` | 战斗胜利/失败立绘 | 2048×2048 |
| `class_<皮肤号>_profile.png` | 资料页立绘 | 1024×1024 |

皮肤号原样写（`4102`、`1003` 这样）。

## 现在有什么、为什么

- `4102/` —— 韦斯（chara 4102，职业 2）。国际服清单 `Resources/manifest/ui_assetmanifest`
  只登记了 `ui_class_4102`（战斗 spine）和 `ui_class_4102_base`（立绘），缩略图/按钮图/
  卡组立绘/资料图/胜负立绘全都没有；同一批的 4101、4103、4104、4105、4107、4108 都有，
  官方持久化目录 `AppData\LocalLow\Cygames\Shadowverse` 里也一样没有。
  卡组立绘和胜负立绘取自国服客户端（国服发过这些包）；国服 bundle 是 Unity 2022 构建的，
  本机运行时是 2020.3，bundle 不能直接用，**贴图可以**，所以提取成 PNG 放这里。

## 以后

国际服资源更新后这些包如果出现了，插件会自动改用官方包（有文件就不兜底），这里的 PNG
可以照常留着，不会覆盖官方素材。
